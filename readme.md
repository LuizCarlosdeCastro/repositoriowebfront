🗂️ Estrutura inicial do Projeto
📁 assets/: Pasta criada para armazenar os icones, imagens, css, videos, fontes da aplicação.
📁 assets/icons/healingrite.ico: Ícone (favicon) de identificação da aplicação que é exibido na aba do navegador.
📁 assets/css/: Pasta criada para armazenar as folhas de estilo.
📁 images/: Pasta criada para armazenar as imagens que serão adicionadas.
📁 pages/index.html: O arquivo principal e ponto de entrada da aplicação.
📁 pages/: onde ficarão as outras páginas da aplicação
